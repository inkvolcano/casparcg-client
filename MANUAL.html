1. Overview

CasparCG Client is a playout control application for CasparCG Server — an open-source video and graphics playout server used in television broadcast, live events, and digital signage. The client provides a visual interface to build rundowns (playlists), trigger media playback, control graphics templates, and monitor output.

Key Capabilities

  • Rundown management — create, edit, save, and load playlists of media and graphics items
  • Multi-server — connect to multiple CasparCG servers simultaneously
  • Live playout — play, stop, update, and transition media with keyboard shortcuts
  • Template graphics — load HTML/Flash templates with data fields for lower thirds, scoreboards, etc.
  • AutoPlay — automatic chaining of items for hands-free sequential playback
  • NDI monitoring — live video preview via NDI directly in the client
  • Customizable layout — rearrange panels, resize, span across columns

2. Getting Started

Requirements

  • Windows 10 or later (64-bit)
  • CasparCG Server 2.2+ running on localhost or a network machine
  • Optional: NDI Runtime for live video monitoring

First Launch

  1. Launch casparcg-client.exe
  2. The client auto-creates a default device ("Localhost" at 127.0.0.1:5250)
  3. Start your CasparCG Server — the client will auto-connect
  4. The Library panel refreshes with available media from the server
  5. Drag items from the Library into the Rundown to build your playlist

Adding a Server

  1. Go to Settings (gear icon or menu)
  2. In the Devices section, click Add
  3. Enter a name, IP address, and port (default 5250)
  4. Optional: set Template path, Media path, and Server path
  5. Click Test Connection to verify, then OK

4. Rundown

The rundown is the central playlist area. It displays items as a vertical tree where each row represents a media clip, graphic template, or control command.

Creating Items

  • Drag from Library — drag any media file, template, or tool from the Library panel into the rundown
  • Double-click in Library — adds the item below the current selection
  • Items are inserted below the currently selected item

Channel/Layer Selector

The Library panel has CH and L spinboxes in its filter row. Items dragged into the rundown automatically inherit the selected channel and video layer, instead of defaulting to CH1/L10.

Editing Items

  • Select — click an item to select it; the Inspector shows its properties
  • Multi-select — hold Ctrl or Shift and click
  • Move — Ctrl+Up/Down to reorder, Ctrl+Right to move into a group, Ctrl+Left to move out
  • Delete — press Delete
  • Duplicate — Ctrl+D
  • Copy/Paste — Ctrl+C / Ctrl+V
  • Cut — Ctrl+X (preserves clone links)

Context Menu

Right-click any item for options including:

  • Copy / Paste / Paste Properties / Paste Properties (No Data)
  • Group / Ungroup
  • Create Linked Clone / Unlink Clone
  • Mark as Used / Unused

Paste Properties (No Data)

A special paste mode that copies all command settings (channel, layer, transition, etc.) from the clipboard but preserves the target item's existing template data/variables. Useful for applying formatting from one template item to another without overwriting its content.

Rundown Hamburger Menu

The ≡ button on the rundown tab bar provides file operations:

  • New Rundown / Open Rundown / Open from Repository / Open Recent
  • Save / Save As
  • Mark Item submenu
  • Compact View toggle
  • Allow Remote Triggering / Lock Rundown
  • Reload / Close Rundown
  • Split Horizontal / Vertical / Close Split

Item Display

Each rundown item shows:

  • Channel badge — colored badge (unique per channel) on the left
  • Item name and label — media filename or custom label
  • Duration — human-readable ("1m23s") or timecode format
  • Delay indicator — hourglass icon with delay value
  • Status icons — overlay on the right (GPI, AutoPlay, loop, etc.)
  • Bottom row — device name, layer, delay, duration, UID

6. Groups

Groups are containers that organize items and control their playback behavior.

Creating Groups

  • Select one or more items and press Ctrl+G or right-click > Group
  • Drag items into an existing group

Nesting

Groups support two levels of nesting:

  • Depth 0 — top-level groups
  • Depth 1 — groups inside groups (inner groups)
  • Items can be at depth 0, 1, or 2

Group Properties

  • Loop — restart the group after the last item finishes
  • AutoPlay — chain to the next group automatically
  • Expanded/Collapsed — click the group header to toggle. Collapsed groups execute all children simultaneously when triggered

Ungrouping

Press Ctrl+U or right-click > Ungroup to dissolve a group and promote its children one level up.

7. AutoPlay

AutoPlay enables automatic sequential playback of items within and across groups.

How It Works

  • Movies preload the next item via LOADBG AUTO for gapless transitions
  • Stills with duration chain to the next item when their timer expires
  • Group AutoPlay chains between groups — when one group finishes, the next starts

Enabling AutoPlay

  • On a group: toggle the AutoPlay icon in the group's status bar, or set it in the Inspector
  • On a still: enable AutoPlay in the Inspector (requires a duration to be set)

Loop

When a group has Loop enabled, it restarts from the first item after the last one finishes. Toggling loop on a playing movie sends a live CALL LOOP command — no need to restart.

Inner Groups

  • Expanded inner group: children are flattened into the parent's autoplay queue
  • Collapsed inner group: all children execute at once as a single batch

8. Gateways

Gateways are special items that route playback, focus, or commands to different locations in the rundown. Each gateway has an entrance and one or more exits.

AutoPlay Gateway (Teal)

Routes the autoplay chain to a different location. When playback reaches the entrance, it jumps to the items after the selected exit and continues autoplay from there.

Focus Gateway (Purple)

UI-only navigation — jumps the visual selection/focus to the exit location without executing any playout commands. Useful for operator navigation.

Command Gateway (Orange)

Relays playout commands (Play, Stop, etc.) to items at the exit location. Supports time-based conditional branching.

Time Conditions

All gateway entrances support time-based conditions:

  • Enable "time condition" in the Inspector
  • Operators: "is after", "is before", "is at or after", "is at or before", "equals"
  • Configure a time (HH:MM:SS) and a "Then" exit vs. "Else" exit
  • The entrance buttons update in real-time to show which exit is currently active

Cross-Tab Gateways

Gateways work across tabs — an entrance in one rundown tab can route to an exit in a different tab.

9. Trigger Banks

Nine configurable trigger banks (B1–B9) for instant access to any item.

Assigning Items

  • Select a rundown item and set its bank number in the Inspector
  • A bank badge overlay appears on the item

Triggering

  • Press Ctrl+1 through Ctrl+9 to trigger the assigned item
  • The Trigger Banks panel shows current assignments with item names and channel badges

10. Linked Clones

Linked clones are items that share properties — change one and all siblings update automatically.

Creating Clones

  • Right-click > Create Linked Clone
  • Ctrl+Shift+V — paste copied items as new linked clones

Managing Clones

  • Cloned items show a blue link badge
  • Right-click > Unlink Clone to break the link
  • When a clone group drops to one member, it auto-unlinks
  • Cut/paste preserves clone links; regular copy/paste creates independent items

11. Library Panel

The Library panel shows media available on connected CasparCG servers, organized into sections.

Sections

  • Tools — built-in item types (Library, Mixer, Other)
  • Audio — audio files from the server
  • Images — still image files
  • Templates — HTML and Flash templates
  • Videos — video files (with duration column)
  • Stored Data — saved template data sets
  • Presets — saved item presets

Filter Row

At the bottom of the Library panel:

  • Search box — type to filter items by name
  • CH / L spinboxes — set the default channel and layer for dragged items
  • Device filter — filter by connected server

Refreshing

  • Right-click the Library for refresh options
  • Enable Auto Refresh Library in Settings for periodic updates

12. Inspector Panel

The Inspector shows and edits properties of the currently selected rundown item. It updates in real-time as you select different items.

13. Templates

Template Data

Template items have a key-value table for data fields. Each row represents a variable sent to the HTML/Flash template.

Data Edit Modes

Each data row has its own edit mode:

ModeBehavior
TextPlain text value (default)
IntegerUp/down arrows increment by 1; preserves zero-padding
DecimalUp/down arrows increment by 0.1
BooleanToggle between "true" and "false"
ColorColor swatch opens a color picker; stores as "#rrggbb"
CycleCycles through pipe-separated values (e.g., "left|center|right")

Multi-Row Invoke

The Invoke section (between Output and Template in the Inspector) supports multiple invoke labels:

  • Add/remove rows with [+] and [-] buttons
  • Each row has a text field, play button, and F7 radio button
  • The radio-selected invoke is used for F7 and OSC invoke commands

Newline Behavior

Per-item dropdown controlling how newlines in template data are encoded:

  • Ignore — strips newlines
  • innerText — encodes as &#10;
  • innerHTML (default) — replaces with <br> tags

14. Preview Panel

Video Playback

When a video item is selected and the server has a Media path configured, the Preview panel plays the actual video file locally with transport controls (play/pause, seek slider, time display).

Content Zoom

  • Double-click to zoom to 150%
  • Double-click again to return to fit view
  • When zoomed: drag to pan, blue "150%" badge, blue border

15. Preview Mode

Preview mode redirects playout commands to a dedicated preview channel.

Activation

  • Modifier key — hold Shift/Ctrl/Alt (configurable) while pressing a playout key
  • PVW button — toggle in the Server Status panel for persistent preview mode
  • Hotkey — Ctrl+P (default) to toggle

Setup

Configure a preview channel per device in Settings > Devices > "Preview on channel" checkbox.

16. NDI Panel

Live video monitoring from CasparCG's built-in NDI output.

Setup

  1. Install the free NDI Runtime
  2. Configure an NDI consumer on your CasparCG server channel
  3. Right-click a viewer > Set Source to select the NDI source

Features

  • Multi-output grid — 1 to 9 simultaneous viewers in configurable layouts
  • Audio — per-viewer audio playback with mute toggle
  • Auto-recovery — reconnects automatically when a source comes back online
  • Quality settings — Bandwidth (High/Low), Frame Rate Limit, Scaling (Smooth/Fast)

17. Audio Meters

The Audio Levels panel shows per-channel audio meters for all connected servers.

  • One tab per server channel (e.g., "CH 1", "CH 2")
  • Each tab has 8 audio level meters (channels 1–8)
  • With multiple servers: tabs include the device name
  • Audio levels are always live — independent of rundown selection
  • Tabs rebuild automatically when devices connect or disconnect

18. Status Panel

Server Status

  • Connection status dot (green/red) per device
  • Media data received dot
  • Connect/Disconnect button
  • Start/Restart buttons (when server path is configured)

Channel Lock Grid

Per-channel lock buttons prevent accidental playout on specific channels. Click a channel button to lock/unlock. Global lock buttons affect all devices.

PVW Button

Green when active. Click to toggle persistent preview mode.

STEP Button

Purple when active. Click to toggle autostep mode.

19. Server Process Management

Start, stop, and restart CasparCG server processes directly from the Status Panel.

Setup

  1. Go to Settings > Devices > Edit device
  2. Set the Server path to the CasparCG server executable (e.g., C:\CasparCG\casparcg.exe)
  3. Start and Restart buttons appear in the Status Panel for that device

Actions

  • Start — launches the server process; button changes to "Stop"
  • Stop — disconnects AMCP and kills the process (with confirmation)
  • Restart — stops then immediately restarts (with confirmation)
  • Auto-reconnects AMCP 3 seconds after start/restart

20. Activity Monitor

Live "now playing" display in the Activity tab of the Status Panel.

  • Progress bars for videos, audio, and stills with duration
  • Countdown timer per entry
  • Type badges (VIDEO, IMAGE, TEMPLATE, AUDIO) with color coding
  • Loop and pause indicators
  • Channel grouping with headers
  • Auto-cleanup of stale entries

Auto-Grow

The Activity panel auto-grows to fit its content. A "Show No Activity" toggle shows a placeholder when empty.

Minimum Height

Set a floor height (30px, 50px, 80px, 100px) via the hamburger menu to prevent collapsing to zero.

21. Clock Widget

Dual-timezone clock with LCD segment-style digits.

  • Two side-by-side or stacked clocks
  • GMT offset labels (auto-updates for DST)
  • Configurable digit colors and shadow color
  • Timezone selection in Settings (e.g., "Europe/Amsterdam (GMT+1)")

22. Performance Panel

Real-time system statistics updated every 2 seconds:

RowShows
ClientCasparCG Client CPU usage and RAM
ServerAggregated CPU and RAM of all CasparCG server processes
SystemTotal system memory and CPU usage

Values are color-coded: green (normal), yellow (moderate), red (high).

23. HTTP Log Panel

Shows responses from HTTP GET and POST commands executed from the rundown:

  • Timestamp, method (GET/POST), URL, HTTP status code
  • Response body (truncated to 500 characters)
  • Auto-scrolls to latest; caps at 1000 entries
  • Clear log via hamburger menu

24. Status Bar

Foldable message log that shows the latest status message. Click the arrow to expand and see the last 10 messages with timestamps. Error messages are highlighted in red.

Last Action Display

Enable "Show last action in statusbar" in Settings to display the most recent playout action (e.g., "Play: ItemName on Server CH1-L10"). Off by default.

25. Split View

Split the rundown area into two panes for working with multiple rundowns simultaneously.

  • Split Horizontal/Vertical via the rundown hamburger menu
  • Double-tap arrow key to switch focus between panes
  • Drag tabs between panes
  • Ctrl+] / Ctrl+[ to cycle tabs in the active pane
  • Close Split to return to single pane

26. Undo / Redo

Full snapshot-based undo/redo with independent stacks per rundown tab.

  • Ctrl+Z — Undo
  • Ctrl+Y or Ctrl+Shift+Z — Redo
  • Captures the full tree state before each editing operation
  • Multi-step operations (e.g., paste multiple items) are grouped into a single undo action

27. Rundown Search

Press Ctrl+F to open a search bar above the rundown tabs.

  • Searches item names and labels (case-insensitive)
  • Match counter shows "1 of N"
  • ▲ / ▼ buttons or Enter to cycle through results
  • Escape or click ✕ to close
  • Each match is selected and scrolled into view
  • Searches inside groups (children included)

28. Rundown Lock

Lock a rundown tab to prevent accidental edits.

  • Toggle via the rundown hamburger menu > Lock Rundown
  • When locked: drag-and-drop, delete, paste, cut, group/ungroup, and move are all disabled
  • Copy and playback commands still work
  • Locked tabs show a 🔒 prefix in the tab title
  • Repository rundowns are locked automatically on load

29. Autostep Mode

Global toggle that automatically advances selection to the next item after pressing Play.

  • STEP button in the Server Status panel (purple when active)
  • Ctrl+Shift+N to toggle
  • Purple background highlight on the autostep item
  • Group-aware: expanded groups step into first child; collapsed groups stay selected

30. Panic Button

Double-tap Escape to instantly clear all outputs on all connected servers.

  1. First press arms the panic and shows a statusbar hint
  2. Second press within 500ms sends CLEAR to every channel on every device
  3. Red statusbar notification: "PANIC: Cleared all outputs"
  4. Auto-disarms after 500ms if no second press

35. Database

All settings are stored in a local SQLite database that persists across restarts. The database auto-migrates when updating to a new version — no manual steps required.

Database location is shown in Settings. To reset to defaults, delete the database file and restart.

Backup tip: Before major updates, copy your database file to a safe location. The database contains all device configurations, layout settings, hotkey mappings, and color customizations.
